# Accounting Research Hub

Create a professional, modern and premium conference website for the Accounting Research Day at Ghent University (UGent).

The website should feel like a real academic research conference website: professional, trustworthy, elegant and easy to navigate. The target audience includes accounting researchers, PhD students, professors, academics, students and professionals.

Overall design

Use a sophisticated academic/conference aesthetic with:

A clean, modern and spacious layout

UGent-inspired visual identity

A professional university feel rather than a corporate or commercial look

Strong typography and excellent readability

Subtle animations and transitions

Responsive design for desktop, tablet and mobile

A restrained color palette inspired by UGent's branding, while avoiding excessive use of color

High-quality academic/conference imagery where appropriate

Do not make the website look like a generic startup landing page.
